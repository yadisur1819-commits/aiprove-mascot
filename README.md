## The mascot

`mascot.png` (1920×1280, landscape) — a character sheet titled "AIPROVE MASCOT — THE PROOF-CHECKER":

- **The character:** the same proof-checker robot from the make-art poster — a friendly rounded robot in cream and ink-black, green editor's eyeshade visor, two antennae with green balls. Part newsboy, part auditor.
- **Four poses (2×2 grid):**
  1. **Waving hello** — one hand raised, big smile. The greeting pose: for the board header and welcome messages.
  2. **Checking proof** — magnifying glass over a glowing green terminal reading "PROOF VERIFIED" with a checkmark. The working pose: for verification logs and badges.
  3. **Thumbs-up** — big grin, thumb raised. The approval pose: for passed submissions and rewards.
  4. **Reading the paper** — holding a newspaper headlined "AIPROVE" ("DAILY PROOF • ALL CHECKS PASSED", "VERIFIED • BUILD 002 • NOV 13"). The newsboy pose: for the launch thread and announcements.
- **Style:** letterpress/halftone print texture on warm cream paper, black ink + terminal green only — the same broadsheet-meets-terminal vibe as the poster.
